## Pairing

Link your WhatsApp securely with the pairing code shown in your deployment console:

1. Start the deployment and watch the console.
2. A pairing code appears in the console.
3. On your phone, open **WhatsApp → Settings → Linked Devices → Link with phone number instead**.
4. Enter the pairing code. When the console confirms the connection, the bot is live.

> Use a **second WhatsApp number** for the bot, never your main personal number.

## Deploy on Panel (Bot-Hosting Free)

| <a href="https://github.com/aryanvoice9-max/GM-SHAH-MD-BOT/archive/refs/heads/main.zip"><img src="https://img.shields.io/badge/DOWNLOAD_ZIP_For_Panel-AB82FF?style=for-the-badge&logo=github&logoColor=white&labelColor=0F0529" alt="Download ZIP"/></a> |
| --- |

1. Create a new **Node.js** deployment on [Bot-Hosting.net](https://bot-hosting.net).
2. Choose **GitHub** as the source and select this repository, branch `main` — or upload the ZIP above.
3. Make sure `index.js` and `package.json` sit at the deployment root (`/home/container/index.js`).
4. Set **Node version 20** in Startup settings.
5. Install command:

   ```bash
   npm install --legacy-peer-deps
   ```

6. Start command:

   ```bash
   node --max-old-space-size=200 index.js
   ```

7. Add the environment variables below, start the deployment, and pair with the console code.

> **Free plan note:** renew the free plan every 4 days (Deployment → Renew now → Renew free plan → Renew for 4 days), otherwise the deployment suspends and the bot stops.

*Keep your bot updated regularly to enjoy the latest features and patches.*

## Environment Variables

| Variable | Description |
|---|---|
| `OWNER_NUMBER` | Bot owner WhatsApp number with country code, no `+` |
| `OWNER_NAME` | Owner name shown in the menu |
| `BOT_NAME` | Bot name (default: GM SHAH MD BOT) |
| `MODE` | `public` or `private` |
| `PREFIXES` | Command prefixes, comma separated |
| `SESSION` | Session string (optional, if you use session login) |
| `TZ` | Timezone, e.g. `Asia/Karachi` |
| `MENU_IMAGES` | Extra menu image URLs, comma separated (optional) |
| `ANTICALL` / `ANTIDELETE` / `ANTIEDIT` | `on` or `off` |
| `AUTO_READ` / `AUTO_VIEW` / `AUTO_LIKE` | `on` or `off` |
| `ACRCLOUD_ACCESS_KEY` / `ACRCLOUD_ACCESS_SECRET` | Optional, for music recognition |
| `GOOGLE_API_KEY` / `GOOGLE_CX` | Optional, for Google search |
| `OMDB_API_KEY` | Optional, for movie info |
| `RAGANORK_API_KEY` | Optional, for text effects |
| `TENOR_API_KEY` | Optional, for GIF search |
| `WEATHER_API_KEY` | Optional, for weather |
| `IMGBB_API_KEY` | Optional, for image uploads |
| `LEPTON_API_KEY` | Optional, for AI fallback |
| `REMOVEBG_API_KEY` | Optional, for `.removebg` background removal |

See [`.env-sample`](.env-sample) for the full list. Keep every key in environment variables, never in code.
